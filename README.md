# 🔧 Serwis Kotłów BQQ - Aplikacja Android

Mobilna aplikacja do zarządzania usługami serwisowania kotłów grzewczych.

## Funkcje

- ✅ Zarządzanie klientami (karty, dane kontaktowe)
- ✅ Historia serwisów
- ✅ Dokumentacja fotograficzna
- ✅ Notatki i uwagi
- ✅ Export danych (Excel, JSON)
- ✅ Powiadomienia o wizytach
- ✅ Offline (localStorage)

## Budowanie APK

Android: Pobierz APK z GitHub Actions
Dev: `npm install && npm start`
